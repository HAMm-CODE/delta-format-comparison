# Attribution

This project began as my solution to Exercise 6 of COMP.CS.320
Data-Intensive Programming at Tampere University (2025). The original
exercise notebook is Copyright 2025 Tampere University, author
Ville Heikkilä, released under the MIT License.

The code in `src/` has been rewritten to remove the Databricks-only
dependencies (`dbutils`, `display`) and the course storage paths, to
run locally and on Databricks, and to be covered by tests. The
synthetic data generator and the benchmark harness are original work.

The original exercise used a subset of the US Accidents dataset
(Moosavi et al., CC BY-NC-SA 4.0), which is not redistributed here.
